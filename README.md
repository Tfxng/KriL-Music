# KriL Music

KriL Music — плеер для Windows. Добавляй свою музыку, собирай плейлисты и настраивай звук и внешний вид под себя. Локальные песни работают без интернета и остаются на твоём компьютере.

Есть очередь, эквалайзер и звуковые эффекты, тексты песен с таймкодами, свои обои и поиск по открытым онлайн-каталогам. Музыку можно добавить файлами, папкой или по ссылке на YouTube.

## Скачать

[KriL Music 2.0.4 — переносимая версия](https://github.com/Tfxng/KriL-Music/releases/download/v2.0.4/KriL-Music-Portable-2.0.4.zip). Распакуй архив целиком и запусти `KriL Music.exe` внутри папки. Песен и личных настроек в архиве нет.

[Все версии и описание изменений](https://github.com/Tfxng/KriL-Music/releases).

## Что нового в 2.0.4

Теперь при добавлении песни по ссылке YouTube можно сразу скачать и видео для её фона. Оно привяжется к этой песне, пойдёт без звука и будет следовать за паузой и перемоткой. Галочка включена сразу, но её можно снять, если нужен только звук.

Если подходящее видео не нашлось, песня всё равно добавится в плейлист. Ранее добавленный ролик можно заменить своим MP4 или WebM через меню трека, а видимость настроить в «Настройки → Визуал → Видео».

Версия 2.0.4 пока доступна архивом. Последний установщик — 2.0.2, поэтому уведомление об обновлении внутри старой версии появится после выхода нового установщика.
